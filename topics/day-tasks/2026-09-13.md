# Day 2 (2026-09-13) -- 10 tasks in one day

Narek asked for a bigger batch today instead of the usual one-exercise
pace. All 10 are posed unsolved -- nothing here is pre-solved. Work
through them in whatever order makes sense; they don't depend on each
other except where noted.

1. **SQL** -- `topics/sql/exercises.sql` (schema in `topics/sql/schema.sql`)
   5 queries: Toronto customers, per-customer totals (INNER JOIN),
   customers with zero orders (LEFT JOIN anti-pattern), most recent

2. **Python** -- `topics/python/palindrome.py`
   `is_palindrome()` ignoring case/punctuation/spaces.
3. **Unix/shell** -- `topics/unix/word_frequency.sh`
   Top-5 word frequency via a `tr | sort | uniq -c | sort | head` pipeline.
4. **Git** -- `topics/git/day2-branch-practice.md`
   Actually branch/commit/merge/delete, then document what you ran.
5. **CS fundamentals (algorithms)** -- `topics/cs-fundamentals/two_sum.py`
   Classic two-sum via hash map, O(n) instead of O(n^2).
6. **CS fundamentals (data structures)** -- `topics/cs-fundamentals/linked_list.py`
   Singly linked list: append, prepend, find, to_list.
7. **Python** -- `topics/python/csv_stats.py`
   Read a CSV, print min/max/mean of a numeric column.
8. **Unix/shell** -- `topics/unix/find_recent_matches.sh`
   Combine `find -mtime` with `grep -l` across two filter axes.
9. **ABAP/RAP** -- `topics/abap/day2-concept-notes.md`
   Explain one RAP concept from your portfolio project in your own words.
10. **Open source** -- `topics/opensource/day2-first-contribution.md`
    Find and act on a real "good first issue" on GitHub (not a kata --
    an actual outside repo).

## Rule for all of them

No solutions are provided. Run/test each one until it actually works,
then commit (and push, since that's your own GitHub auth) as you go --
doesn't have to be one giant commit at the end.

Going forward, the daily automation returns to posing ONE exercise a
